# 隐私政策（Privacy Policy）

生效日期：2026-08-02

## 概述

「隔空助手 Air Assistant」是一款基于前置摄像头的隔空手势控制应用。**本应用不联网、不收集、不上传任何个人数据**。所有识别处理均在设备本地完成。

## 数据收集

| 数据类型 | 是否收集 | 说明 |
|---|---|---|
| 摄像头画面 | 否 | 仅用于实时手势识别，不保存、不录制、不传输 |
| 手势操作记录 | 否 | 仅在本机内存中短暂存在，用于识别判定 |
| 应用设置 | 是（本地） | 手势映射、坐标、性能模式等配置保存在本机 SharedPreferences |
| 崩溃日志 | 是（本地） | 仅保存在本机，可手动导出，不自动上传 |
| 个人身份信息 | 否 | 不要求注册、不要求任何账户 |

## 摄像头与无障碍服务用途声明

1. **摄像头**：持续调用前置摄像头以识别手部关键点。摄像头画面不会离开本机。
2. **无障碍服务**：用于向系统派发滑动/点击/长按手势（`dispatchGesture`）。本应用不读取、不存储任何第三方应用内容（如微信聊天、浏览器内容等），仅执行用户手势映射的动作。

## 权限

| 权限 | 用途 | 是否可关闭 |
|---|---|---|
| CAMERA | 手势识别核心功能 | 关闭后应用不可用 |
| 无障碍服务 | 派发系统手势 | 关闭后仅识别不操作 |
| SYSTEM_ALERT_WINDOW | 后台悬浮窗预览（可选） | 可关闭 |
| POST_NOTIFICATIONS | 前台服务通知 | 可关闭 |

## 第三方

本应用基于 Google MediaPipe（[Apache-2.0](https://github.com/google-ai-edge/mediapipe-samples)）。MediaPipe 推理在本地执行，不涉及数据传输。

## 安全提醒

- 无障碍服务可模拟用户操作，请仅在可信设备上安装本应用
- 请勿在输入密码、支付等敏感场景使用手势控制
- 请从官方 Releases 渠道下载 APK，避免来源不明的修改包

## 变更

本政策如变更，将更新本页面并随版本发布说明同步。
