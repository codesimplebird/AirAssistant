# 兼容性说明

## 支持的 Android 版本

| 范围 | 状态 | 说明 |
|---|---|---|
| Android 7.0–9（API 24–28） | 基础可用 | 无通知渠道、后台保活弱、低端机性能差；GPU 不支持时自动回退 CPU |
| Android 10–13（API 29–33） | 推荐 | 支持温度自适应（Android 10+）；Android 13 需通知权限 |
| Android 14+（API 34+） | 需重点验证 | 前台服务限制、16KB 内存页（16 KB page size）需逐步适配 |

## 设备要求

- **必须**：前置摄像头、开发者模式（首次安装调试）
- **推荐**：Android 10 及以上、中高端处理器
- **不适用**：无前置摄像头的设备（部分平板）

## 厂商系统差异（后台保活）

厂商 ROM 可能限制后台服务，导致退后台后识别中断：

| 厂商 | 需要设置 |
|---|---|
| MIUI/澎湃 | 应用信息 → 自启动 开启；电池 → 无限制 |
| EMUI/HarmonyOS | 应用启动管理 → 手动管理全部允许；电池 → 不限制 |
| ColorOS | 允许自启动、允许后台运行、电池不限制 |
| OriginOS | 后台耗电管理 → 允许后台高耗电 |
| One UI | 电池 → 不受限制 |

应用内「后台保活」卡片提供电池白名单与 MIUI 自启动入口。

## 屏幕与横竖屏

- 滑动/点击坐标基于运行时 `DisplayMetrics` 换算，不依赖固定分辨率
- 默认竖屏优化；横屏代码有 `onConfigurationChanged` 处理但未充分实测
- 刘海屏/打孔屏：状态栏已做 Insets 避让

## 手势灵敏度

- 挥手阈值：位移 0.20（归一化）、速度 0.0006/ms
- 捏合阈值：指尖距/掌宽 ≤ 0.35 捏合、≥ 0.50 释放，3 帧确认
- 阈值已归一化，大部分设备无需调整；不同镜头视角下识别距离可能变化

## 已知问题

1. 摄像头固定前置
2. 前后台切换存在极低概率竞态（已加防护，未 100% 消除）
3. 悬浮窗在部分 ROM 需要「显示在其他应用上层」授权
4. 无障碍服务在 MIUI 重装/更新后可能被重置，需重新开启

## 性能模式

| 模式 | 有手帧率 | 无手帧率 | 分析分辨率 |
|---|---|---|---|
| 自动 | ~15fps | ~5fps | 480x360 |
| 省电 | ~10fps | ~3-4fps | 320x240 |
| 标准 | ~15fps | ~5fps | 480x360 |
| 高响应 | ~30fps | ~7.5fps | 480x360 |
| （温度严重时自动降档） | ~10fps | ~3-4fps | 320x240 |
